# PASSAGE 阅读记忆复习册

175 篇独立文章，逐段中英对照、完整题组、段首 heading、依据句高亮及全文框架。

每篇提供「遮住答案背诵」：按原顺序单题揭晓，连续填空与摘要整组保留；背诵揭晓不会生成测试成绩。可直接进入本篇测试。

单篇测试支持选择和填空、草稿恢复、翻译开关记忆、真实交卷评分。翻译满分也计入进度；复习页可回看最新测试时的个人答案。

计划页按错题数量安排整篇任务，提供「开始今天任务／继续本篇」；隔天连续满分仅作巩固提示。考试时间 2026-10-28 09:00（北京时间），每天 90 分钟。

「导入原站备份」可在浏览器内预览并合并 PASSAGE 原站备份，保留原分数、个人答案、部分题组和恢复证据标记。不会冒充新的本站记忆测试；新错题可使旧满分重新待复测。重复记录去重，可靠缺失信息可补全，冲突记录不会静默覆盖。

记录保存在当前浏览器。「导出记录／导入记录」可备份并迁移本站测试和导入的原站历史。没有云同步，也不会上传你选取的备份文件。
